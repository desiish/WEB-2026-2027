# Въведение в HTML
 
---
 
## Блок 1 · Увод
 
### Какво е HTML?
 
- **H**yper**T**ext – текст с връзки към други страници
- **M**arkup – маркираме какво е всяка част
- **L**anguage – език с ясни правила
**Маркираме, не програмираме.** Няма условия, цикли и функции – само етикети за съдържанието.
 
```html
<p>Това е параграф</p>
```
 
Тагът казва на браузъра: „покажи това като параграф“.
 
### HTML + CSS + JS
 
Една страница е като тяло:
 
- **HTML** · скелет – структура и съдържание
- **CSS** · дрехи – цветове, размери, подредба
- **JavaScript** · мускули – поведение и интерактивност
Днес учим само скелета – без него другите два нямат върху какво да работят.

## Блок 2 · Структура на документа
 
### Скелетът на HTML файл
 
VS Code: `!` + Enter
 
```html
<!DOCTYPE html>
<html lang="bg">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Заглавие на страницата</title>
    <link rel="icon" href="favicon.ico" />
  </head>
  <body>
    <!-- съдържанието -->
  </body>
</html>
```
 
| Ред | Обяснение |
|---|---|
| `<!DOCTYPE html>` | Казва на браузъра, че документът е HTML5. Не е таг, а декларация. Винаги е на първия ред. |
| `<html lang="bg">` | Обхваща целия документ – всичко останало е вътре в него. `lang="bg"` показва езика – важно за екранни четци и преводачи. |
| `<head>` | Мета информация: заглавие, кодировка, връзки към стилове. Нищо от `<head>` не се показва на страницата. |
| `<meta charset="UTF-8" />` | Кодировката, с която кирилицата се показва правилно. Без нея може да видиш „кракозябри“ вместо букви. |
| `<meta name="viewport" />` | Прави страницата удобна за телефон. Празен таг – затваряме го с `/` в края, без `</meta>`. |
| `<title>` | Текстът в таба на браузъра. Вижда се и в резултатите на търсачките, и в отметките. |
| `<link rel="icon" />` | Favicon – малката иконка в таба на браузъра, до заглавието. Квадратна картинка (.ico, .png или .svg) в папката на сайта. Вижда се и в отметките. Празен таг – с `/` в края. |
| `<body>` | Всичко, което виждаме на страницата. Тук ще пишем заглавия, параграфи, снимки, списъци. |
 
### `<head>` срещу `<body>`
 
Едното браузърът чете, другото – показва.
 
- `<title>` в `<head>` → текстът в таба
- текстът в `<body>` → страницата
- `<head>` – браузърът го чете, но не го рисува: `<meta charset="UTF-8" />`, `<meta name="viewport" ... />`, `<title>`, `<link rel="icon" href="favicon.ico" />` ← иконката в таба
Без UTF-8 браузърът не знае как да чете кирилицата – това са „кракозябри“.
 
### Две свързани страници
 
Всяка страница е отделен файл със свой скелет.
 
```
моят-сайт/
├── index.html
└── about.html
```
 
**index.html**
 
```html
<!DOCTYPE html>
<html lang="bg">
<head>
  <meta charset="UTF-8" />
  <title>Начало</title>
</head>
<body>
  <h1>Здравей!</h1>
  <p>Това е началната страница на моя сайт.</p>
  <a href="about.html">Научи повече за мен</a>
</body>
</html>
```
 
**about.html**
 
```html
<!DOCTYPE html>
<html lang="bg">
<head>
  <meta charset="UTF-8" />
  <title>За мен</title>
</head>
<body>
  <h1>За мен</h1>
  <p>Казвам се Мария и уча HTML.</p>
  <a href="index.html">← Обратно към началото</a>
</body>
</html>
```
 
Двата файла са в една папка – затова `href` е само името на файла.

## Блок 3 · Тагове, елементи, атрибути
 
### Таг → елемент
 
Елемент = отварящ таг + съдържание + затварящ таг
 
| `<h1>` | Текст на заглавието | `</h1>` |
|---|---|---|
| отварящ таг | съдържание | затварящ таг |
 
Какво ще стане, ако не затворим тага?
 
```html
<h1>Моят сайт
<p>Обикновен текст под заглавието.</p>
```
 
Без `</h1>` браузърът „познава“ – и целият текст отдолу става заглавие. Когато тагът е затворен, браузърът знае къде свършва заглавието.
 
### Като руски кукли
 
Последният отворен таг се затваря пръв.
 
```html
<p>Това е <strong>важен</strong> текст.</p>
```
 
Празни тагове – без съдържание и без затварящ таг, с `/` в края:
 
`<img />` · `<br />` · `<hr />` · `<input />`
 
**Намери грешката**
 
```html
<ul>
  <li>Ябълки</li>
  <li><strong>Круши</li></strong>
</ul>
```
 
Правилно: `<li><strong>Круши</strong></li>` – `<strong>` е отворен последен, затова се затваря пръв.
 
```html
<p>Снимка на котка:</p>
<img src="cat.jpg" alt="Котка"></img>
<hr />
```
 
`<img />` е празен таг – няма съдържание и няма затварящ `</img>`. Затваряме го с `/` в края, също като `<hr />` на ред 3.
 
### Атрибути
 
Допълнителна информация – вътре в отварящия таг.
 
```html
<a href="https://w3docs.com">Посети ме</a>
```
 
- `<a` – таг
- `href` – име
- `"https://w3docs.com"` – стойност – винаги в кавички
```html
<a href="https://w3docs.com" target="_blank">Посети ме</a>
```
 
Глобални атрибути – работят на всеки елемент:
 
| Атрибут | |
|---|---|
| `id` | уникален идентификатор |
| `class` | група за стилизиране |
| `title` | подсказка при навеждане |
| `style` | вградени стилове |

## Блок 4 · Базови елементи
 
### Заглавия `<h1>`–`<h6>`
 
```html
<h1>Котките и техните навици</h1>
```
 
- `<h1>` – най-голямото и най-важното заглавие.
- `<h2>` – заглавие на голяма част от страницата.
- `<h3>` – подзаглавие в част.
- `<h4>` – вече е колкото обикновения текст.
- `<h5>` – по-малко от обикновения текст.
- `<h6>` – най-малкото. Ето защо избираме по смисъл, не по размер.
**Правила**
 
1. Един `<h1>` на страница – главното заглавие.
2. Без прескачане на нива: не от h1 направо към h4.
3. Избираме по смисъл, не по размер – размерът е работа на CSS.
### Параграфи `<p>`
 
Без `<p>`:
 
```html
Котките спят по 16 часа на ден.
Те общуват с мъркане.
Обичат топлите места.
```
 
→ Котките спят по 16 часа на ден. Те общуват с мъркане. Обичат топлите места.
 
С `<p>`:
 
```html
<p>Котките спят по 16 часа на ден.</p>
<p>Те общуват с мъркане.</p>
<p>Обичат топлите места.</p>
```
 
```css
/* CSS */
p { background: #FFF1E6; }
```
 
Без `<p>` – `p { }` не намира нищо, няма какво да стилизираме.
 
1. Браузърът знае какво чете
2. Има по какво да стилизираме
3. Четци и търсачки разчитат на структурата
Браузърът свива интервалите и новите редове в един интервал. Нов ред: `<br />` · черта: `<hr />`
 
### Връзки и снимки
 
**`<a>`** – прави текста кликаем
 
```html
<!-- към друг сайт -->
<a href="https://w3docs.com">Уроци</a>
 
<!-- към файл в същата папка -->
<a href="about.html">За мен</a>
 
<!-- в нов таб -->
<a href="..." target="_blank">…</a>
```
 
**`<img />`** – празен таг – без затварящ, с `/` в края
 
```html
<img src="images/cat.jpg" alt="Сива котка на прозорец" />
```
 
- `src` – пътят до снимката
- `alt` – текст за екранни четци и за когато снимката не се зареди
| | | |
|---|---|---|
| **Абсолютен път** | `https://site.com/img.jpg` | целият адрес |
| **Релативен път** | `images/cat.jpg` | спрямо файла, в който пишем |
 
### Списъци
 
`<ol>` – редът има значение · `<ul>` – редът няма значение · всеки елемент е `<li>`
 
**Рецепта за палачинки** → `<ol>` – стъпките имат ред.
 
```html
<ol>
  <li>Разбий яйцата с млякото</li>
  <li>Добави брашното</li>
  <li>Изпечи в тиган</li>
</ol>
```
 
**Списък за пазаруване** → `<ul>` – редът няма значение.
 
```html
<ul type="circle">
  <li>Мляко</li>
  <li>Яйца</li>
  <li>Брашно</li>
</ul>
```
 
Списъците могат да се влагат: нов `<ul>` вътре в `<li>`.
 
### Форматиращи тагове
 
| Таг | |
|---|---|
| `<strong>` | важен текст |
| `<em>` | акцент |
| `<u>` | подчертан |
| `<mark>` | хайлайтър |
| `<small>` | по-малък |
| `<pre>` | пази интервалите |
 
```html
Това е <strong>важно</strong>, а това е <em>акцент</em>.
Учете HTML на <mark>W3Docs.com</mark>.
Цената е 10% <small>* на ден</small>
<pre>Този    текст
   пази интервалите</pre>
```
 
Задача: подчертай думата „важно“.

## Блок 5 · HTML5 и семантика
 
### Има ли версии на HTML?
 
Да – езикът расте.
 
| Година | Версия | |
|---|---|---|
| 1991 | HTML | Тим Бърнърс-Лий описва първите тагове – заглавия, параграфи, връзки. |
| 1995 | HTML 2.0 | Първият официален стандарт. Добавени са форми. |
| 1997 | HTML 3.2 / 4.0 | Таблици, скриптове и стилове. Браузърите растат бързо. |
| 1999 | HTML 4.01 | Изчистена версия на 4.0 – основа на мрежата за години напред. |
| 2000 | XHTML | По-строги правила за писане, като в XML. |
| 2014 | HTML5 | Семантични тагове, аудио и видео, нови полета във формите. Текущата версия. |
| днес | Living Standard | HTML5 се развива постоянно – без нови номера, с малки подобрения. |
 
**Защо HTML5 е полезен**
 
- Поддържа се от всички модерни браузъри
- Работи добре на различни устройства
- Семантични тагове вместо безлични `<div>`
- Аудио и видео без приставки: `<audio>`, `<video>`
- Пази данни в браузъра (localStorage)
- Нови полета във формите: email, date, number
### Content model
 
В HTML5 елементите се делят на групи по смисъл.
 
| Група | Описание | Тагове |
|---|---|---|
| **Metadata** | Информация за самия документ. Живее в `<head>` и не се показва. | `<title>` – текстът в таба · `<meta />` – кодировка, екран за телефон · `<link />` – свързва CSS файл · `<style>` – CSS в самия файл |
| **Flow** | Почти всичко, което се ползва в `<body>`. | `<p>` – параграф текст · `<ul>` – списък с точки · `<img />` – снимка · `<div>` – блок без смисъл |
| **Sectioning** | Дели съдържанието на смислови части – тема по тема. | `<section>` – тематична група · `<article>` – самостоятелна статия · `<nav>` – главно меню · `<aside>` – странично съдържание |
| **Heading** | Заглавията – планът на страницата. | `<h1>` – главно заглавие, едно · `<h2>` – заглавие на раздел · `<h3>` – подзаглавие · `<h4>`–`<h6>` – по-дребни нива |
| **Phrasing** | Текстът и вградените в него елементи. | `<a>` – връзка · `<strong>` – важен текст · `<em>` – акцент · `<span>` – вграден, без смисъл |
 
Има и други групи – embedded, interactive – но тези пет са основните.
 
### `<div>` срещу семантика
 
**Без смисъл**
 
```html
<div class="top">
  <div class="title">Моят блог</div>
  <div class="menu">
    <a href="index.html">Начало</a>
    <a href="about.html">За мен</a>
  </div>
</div>
<div class="content">
  <div class="post">
    <div class="post-title">Първата ми страница</div>
  </div>
</div>
<div class="bottom">© 2026 Моят блог</div>
```
 
Какво чува човек с екранен четец: „Моят блог“ · „Начало“, връзка · „За мен“, връзка · „Първата ми страница“ · „© 2026 Моят блог“
 
Само текст – няма меню, няма заглавия, няма „главно съдържание“. Човекът трябва да слуша всичко подред.
 
**Със смисъл**
 
```html
<header>
  <h1>Моят блог</h1>
  <nav>
    <a href="index.html">Начало</a>
    <a href="about.html">За мен</a>
  </nav>
</header>
<main>
  <article>
    <h2>Първата ми страница</h2>
  </article>
</main>
<footer>© 2026 Моят блог</footer>
```
 
Какво чува човек с екранен четец: **Банер** · Заглавие, ниво 1: „Моят блог“ · **Навигация, 2 връзки** · „Начало“, връзка · „За мен“, връзка · **Основно съдържание** · Статия · Заглавие, ниво 2: „Първата ми страница“ · **Информация за съдържанието**: „© 2026 Моят блог“
 
Четецът обявява ориентири – човекът може да скочи направо до менюто или до главното съдържание.
 
### Още примери
 
**Header**
 
```html
<!-- Без смисъл -->
<div class="header">
  <div class="logo">Лого</div>
  <div class="title">Моят блог</div>
</div>
 
<!-- Със смисъл -->
<header>
  <img src="logo.png" alt="Лого" />
  <h1>Моят блог</h1>
</header>
```
 
- Без смисъл, четецът казва: „Лого. Моят блог.“ – няма как да се разбере, че това е горната част.
- Със смисъл: „Банер. Изображение: Лого. Заглавие, ниво 1: Моят блог.“
- Какво печелим: `<header>` казва „това е горната част“ – обикновено лого, заглавие и меню.
**Main**
 
```html
<!-- Без смисъл -->
<div id="content">
  <div class="title">Последни статии</div>
  <div>Днес научих HTML.</div>
</div>
 
<!-- Със смисъл -->
<main>
  <h2>Последни статии</h2>
  <p>Днес научих HTML.</p>
</main>
```
 
- Без смисъл: „Последни статии. Днес научих HTML.“ – човекът трябва първо да изслуша цялото меню.
- Със смисъл: „Основно съдържание. Заглавие, ниво 2: Последни статии…“
- Какво печелим: с един клавиш се прескача менюто направо до `<main>`. На страница има само един `<main>`.
**Footer**
 
```html
<!-- Без смисъл -->
<div class="footer">
  <div>© 2026 Моят блог</div>
  <div>Пиши ми: maria@site.bg</div>
</div>
 
<!-- Със смисъл -->
<footer>
  <p>© 2026 Моят блог</p>
  <p><a href="mailto:maria@site.bg">Пиши ми</a></p>
</footer>
```
 
- Без смисъл: „© 2026 Моят блог. Пиши ми: maria@site.bg“
- Със смисъл: „Информация за съдържанието. © 2026 Моят блог. Пиши ми, връзка.“
- Какво печелим: `<footer>` събира контакти и авторски права – четци и търсачки знаят, че това е краят на страницата.
**Заглавие**
 
```html
<!-- Без смисъл -->
<div class="big-title">За мен</div>
<div>Уча HTML от една седмица.</div>
 
<!-- Със смисъл -->
<h2>За мен</h2>
<p>Уча HTML от една седмица.</p>
```
 
- Без смисъл: „За мен. Уча HTML от една седмица.“
- Със смисъл: „Заглавие, ниво 2: За мен.“ – и човекът може да прескача от заглавие на заглавие.
- Какво печелим: заглавията са планът на страницата – по тях навигират четците и търсачките.
**Важен текст**
 
```html
<!-- Без смисъл -->
<p>
  <span class="bold">Внимание!</span>
  Изпитът е в петък.
</p>
 
<!-- Със смисъл -->
<p>
  <strong>Внимание!</strong>
  Изпитът е в петък.
</p>
```
 
- Без смисъл: „Внимание! Изпитът е в петък.“ – удебеляването се вижда, но не се чува.
- Със смисъл: подчертава „Внимание!“ като важен текст.
- Какво печелим: `<strong>` носи смисъла „важно“; `<span class="bold">` е само външен вид.
**Бутон**
 
```html
<!-- Без смисъл -->
<div class="btn" onclick="send()">
  Изпрати
</div>
 
<!-- Със смисъл -->
<button onclick="send()">
  Изпрати
</button>
```
 
- Без смисъл: „Изпрати“ – и не може да се стигне с Tab.
- Със смисъл: „Изпрати, бутон“ – стига се с Tab и се натиска с Enter.
- Какво печелим: `<button>` работи с клавиатура без нито ред допълнителен код.
**Меню**
 
```html
<!-- Без смисъл -->
<div class="menu">
  <a href="index.html">Начало</a>
  <a href="blog.html">Блог</a>
  <a href="about.html">За мен</a>
</div>
 
<!-- Със смисъл -->
<nav>
  <ul>
    <li><a href="index.html">Начало</a></li>
    <li><a href="blog.html">Блог</a></li>
    <li><a href="about.html">За мен</a></li>
  </ul>
</nav>
```
 
- Без смисъл: „Начало, връзка. Блог, връзка. За мен, връзка.“
- Със смисъл: „Навигация. Списък, 3 елемента. Начало, връзка…“
- Какво печелим: четецът казва, че това е менюто и колко пункта има – и може да скочи до него.
**Дата**
 
```html
<!-- Без смисъл -->
<div class="date">
  12.10.2026
</div>
 
<!-- Със смисъл -->
<time datetime="2026-10-12">
  12 октомври 2026
</time>
```
 
- Без смисъл: „12.10.2026“ – просто числа.
- Със смисъл: „12 октомври 2026“ – а машините четат точната дата от `datetime`.
- Какво печелим: търсачки и календари разбират датата, без да гадаят формата.
### Карта на семантична страница
 
| Таг | Зона |
|---|---|
| `<header>` | горна част: лого и заглавие |
| `<nav>` | главно меню с връзки |
| `<main>` | главното съдържание (един на страница) |
| `<section>` | тематична група „За мен“ |
| `<article>` | самостоятелен пост |
| `<aside>` | странично: свързани връзки |
| `<footer>` | долна част: контакти, авторски права |

## Блок 6 · Практика и обобщение
 
### Браузър детектив
 
**Случай 1** – Симптом: удебеленият текст „изтича“ надолу по страницата.
 
```html
<h2>Новини</h2>
<p>Това е <strong>важен</p></strong>
<p>Край на новините.</p>
```
 
Грешен ред на затваряне. Последният отворен (`<strong>`) се затваря пръв.
Поправка: `<p>Това е <strong>важен</strong></p>`
 
**Случай 2** – Симптом: една от връзките в менюто не води, където трябва.
 
```html
<nav>
  <a href="index.html">Начало</a>
  <a href=https://w3docs.com>Уроци</a>
</nav>
```
 
Липсват кавички около стойността на атрибута.
Поправка: `<a href="https://w3docs.com">Уроци</a>`
 
**Случай 3** – Симптом: в папката има файл `images/cat.jpg`, но снимката не се вижда на сървъра.
 
```html
<h1>Моята котка</h1>
<img src="images/Cat.jpg" alt="Котка" />
<p>Тя обича да спи.</p>
```
 
Грешен път: `Cat.jpg` ≠ `cat.jpg`. На сървъра главните и малките букви имат значение.
Поправка: `<img src="images/cat.jpg" alt="Котка" />`
 
**Случай 4** – Симптом: страницата изглежда добре, но планът ѝ е объркан за четци и търсачки.
 
```html
<h1>Моят блог</h1>
<h4>Последни статии</h4>
<p>Днес научих HTML.</p>
```
 
Прескачане на нива – от `<h1>` направо към `<h4>`, само защото „е по-малко“. Заглавията се избират по смисъл.
Поправка: `<h2>Последни статии</h2>`
 
> **F12** – Съвет: F12 или десен клик → Inspect на всяка страница показва истинския HTML – можеш да го променяш на живо, без да счупиш сайта.
 
### Да обобщим
 
1. HTML е език за маркиране – описва структура и смисъл, не логика.
2. Елемент = отварящ таг + съдържание + затварящ таг; атрибутите допълват отварящия.
3. `<head>` е невидимото, `<body>` – видимото.
4. Семантични тагове вместо навсякъде `<div>`.
**Тест**
 
1. **Каква е разликата между таг и елемент?**
   А) Няма разлика – това са синоними · Б) Елементът е отварящ таг + съдържание + затварящ таг · В) Тагът винаги е по-голям от елемента
   <details><summary>Отговор</summary>Б. Тагът е само <code>&lt;p&gt;</code> или <code>&lt;/p&gt;</code>; елементът е цялото: <code>&lt;p&gt;Текст&lt;/p&gt;</code>.</details>
2. **Къде пишем `<title>` и `<meta charset="UTF-8" />`?**
   А) `<head>` · Б) `<body>` · В) `<footer>`
   <details><summary>Отговор</summary>А. В <code>&lt;head&gt;</code> е информацията за документа – тя не се показва на страницата.</details>
3. **Кой таг ще избереш за главно меню?**
   А) `<div>` · Б) `<nav>` · В) `<menu-bar>`
   <details><summary>Отговор</summary>Б. <code>&lt;nav&gt;</code> казва на браузъра и на четците „тук е менюто“. <code>&lt;div&gt;</code> не казва нищо.</details>
4. **Списък със стъпките на рецепта – кой таг?**
   А) `<ol>` · Б) `<ul>` · В) `<li>` без списък
   <details><summary>Отговор</summary>А. Редът на стъпките има значение, затова е нумериран списък <code>&lt;ol&gt;</code>.</details>
5. **Кое е затворено правилно?**
   А) `<p><strong>текст</p></strong>` · Б) `<p><strong>текст</strong></p>` · В) `<p><strong>текст</strong>`
   <details><summary>Отговор</summary>Б. Последният отворен (<code>&lt;strong&gt;</code>) се затваря пръв, после <code>&lt;p&gt;</code>.</details>
6. **HTML е…**
   А) програмен език с цикли и условия · Б) език за маркиране на съдържание · В) език за цветове и шрифтове
   <details><summary>Отговор</summary>Б. HTML маркира какво е всяка част. Цветовете са CSS, логиката – JavaScript.</details>

 
### Мини-проект „Лична визитка“
 
Чеклист:
 
- [ ] `<header>` с `<h1>` – твоето име
- [ ] `<nav>` с две връзки
- [ ] Снимка `<img />` с alt
- [ ] Хобита в `<ul>` списък
- [ ] Връзка, която се отваря в нов таб
- [ ] `<footer>` с контакт

```html
<!DOCTYPE html>
<html lang="bg">
<head>
  <meta charset="UTF-8" />
  <title>Лична визитка</title>
</head>
<body>
  <!-- Започни тук -->
 
</body>
</html>
```
